# 057. CI для кода, контрактов и моделей

## Результат обучения

Проверять финансовые изменения до merge.

## Как это работает

CI должен запускать быстрые unit tests, fixture transformations и документационные проверки. Production credentials для локальной фикстуры не нужны. Изменение схемы проверяется на old и new fixtures; денежная формула — на явном expected result. Изменение links проверяется отдельно от корректности знаний.

## Пример из финтеха

PR меняет знак fee; CI должен показать изменение USD итога, а не только синтаксический успех.

## Порядок реализации

1. Запусти unit tests
2. Запусти SQL expected checks
3. Проверь local links
4. Прочитай бизнес-diff.

## Практическое задание

Измени знак fee в ветке своего форка и убедись, что meaningful assertion падает.
