# 021. OLTP, DWH, lake и lakehouse

## Результат обучения

Обосновать выбор системы по нагрузке и требованиям истории.

## Как это работает

OLTP оптимизирует короткие операции над текущим состоянием. DWH обслуживает аналитическое чтение и согласованные модели. Data lake хранит файлы разных форматов; lakehouse добавляет табличные метаданные и управляемые изменения поверх object storage. Эти роли могут пересекаться, но название продукта не гарантирует качество данных.

## Пример из финтеха

Платёжный сервис не должен ждать тяжёлый месячный GROUP BY аналитика.

## Порядок реализации

1. Измерь operational workload
2. Определи аналитические запросы
3. Назови требования истории
4. Раздели source и analytical serving.
