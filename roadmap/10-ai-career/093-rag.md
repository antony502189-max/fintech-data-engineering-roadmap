# 093. RAG по каталогу данных и права документов

## Результат обучения

Дать ответы с источниками, не обходя access boundaries.

## Как это работает

RAG ищет релевантные документы и передаёт их модели. Retrieval должен фильтровать права до выдачи context; скрытый документ в prompt уже является утечкой. Citation должна ссылаться на реально выбранный fragment и его version. Отсутствие подтверждения не лечится более уверенным тоном модели.

## Пример из финтеха

Finance user читает определение net cash, support user не получает закрытое описание fraud rules.

## Порядок реализации

1. Определи document ACL
2. Фильтруй retrieval
3. Сохрани version refs
4. Проверяй answer grounding.

## Практическое задание

На offline list документов реализуй role-filtered retrieval и тест forbidden document.

## Типичная ошибка и её последствия

Сначала получают все chunks, а затем просят модель не раскрывать секреты.

## Проверка результата

В context support роли никогда не попадает restricted chunk.

## Вопрос для самопроверки

Как deletion документа должен распространяться на embeddings и caches?
