# 093. RAG over the data catalog and document permissions

## Learning outcome

Answer with evidence without bypassing access boundaries.

## How it works

Retrieval selects documents for model context. Filter access before sharing context; a hidden document in a prompt is already exposed. Citations must identify actual retrieved fragments and versions. Missing evidence cannot be repaired with more confident wording.

## Fintech example

Finance can retrieve cash definitions; support cannot access restricted fraud rules.

## Implementation steps

1. Define document ACLs
2. Filter before retrieval context
3. Preserve version references
4. Verify grounded claims.

## Practical assignment

Implement role-filtered retrieval over offline documents and test forbidden content.

## Common mistake and its consequences

Retrieving everything and asking the model to hide secrets exposes restricted material.

## Verify the result

Restricted chunks never enter a support user's context.

## Self-check question

How should document deletion propagate to embeddings and caches?
