# 003. Python для надёжных пайплайнов

## Результат обучения

Написать чистую функцию преобразования и отделить её от ввода-вывода.

## Как это работает

Разделяй чтение источника, проверку контракта, преобразование и запись. Чистые функции проще проверять на граничных значениях. Генератор помогает читать поток порциями, но сам по себе не гарантирует ограниченную память: накопление списка в следующем шаге отменяет эффект. Ошибка формата и временный сетевой сбой требуют разных обработчиков.

## Пример из финтеха

CSV провайдера содержит суммы строками и валюту отдельно. Парсер должен отклонить лишнюю точность, а не округлить её незаметно.

## Порядок реализации

1. Прочитай fintech_lab/money.py
2. Проверь Decimal и преобразование в minor units
3. Отдели бизнес-ошибки от инфраструктурных
4. Добавь обработку ошибки на границе.

## Практическое задание

Расширь локальную копию функции to_minor новой синтетической валютой с четырьмя знаками; добавь проверки допустимой и недопустимой точности.
