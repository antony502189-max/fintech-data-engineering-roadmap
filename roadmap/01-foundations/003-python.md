# 003. Python для надёжных пайплайнов

## Результат обучения

Написать чистую функцию преобразования и отделить её от ввода-вывода.

## Как это работает

Разделяй чтение источника, проверку контракта, преобразование и запись. Чистые функции проще проверять на граничных значениях. Генератор помогает читать поток порциями, но сам по себе не гарантирует ограниченную память: накопление списка в следующем шаге отменяет эффект. Ошибка формата и временный сетевой сбой требуют разных обработчиков.
