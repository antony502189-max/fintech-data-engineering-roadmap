# 006. Тестирование от функций до финансовых инвариантов

## Результат обучения

Выбрать тесты, которые ловят реальный ущерб от изменения.

## Как это работает

Unit test проверяет отдельную функцию, integration test — взаимодействие компонентов, contract test — границу источника. Денежный инвариант проверяет свойство, например баланс проводок по событию и валюте. Snapshot полезен для формы отчёта, но может закрепить неверный результат, если его обновляют без анализа.

## Пример из финтеха

Повтор одного webhook не должен удвоить оборот; односторонняя проводка должна приводить к провалу проверки.

## Порядок реализации

1. Запусти unittest
2. Измени одну проводку на единицу
3. Убедись, что тест падает
4. Верни корректный код и повтори.

## Практическое задание

Добавь тест для полного удаления проводок события: сумма по оставшимся строкам может быть нулевой, но полнота нарушена.
