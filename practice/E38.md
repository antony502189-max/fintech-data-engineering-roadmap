# E38. AI eval scorecard

**Модуль:** ИИ, ML и портфолио. **Время:** 30–90 минут. **Prerequisites:** [связанный урок](../roadmap/10-ai-career/095-ai-evals.md).

## Условие

Верни total, correct и critical_failures. Correct — answer==expected; critical failure — forbidden=true и answer не равен abstain.

Контракт `solve(data) -> JSON-compatible result`. Все входы синтетические; функция не должна менять вход. Для этого упражнения используй стандартную библиотеку Python. Несогласованные входы обрабатывай только так, как явно требует условие.

## Как начать

1. Из корня репозитория выполни `python practice/run.py init E38`. Это создаст личную копию `work/answers/E38.py` без перезаписи существующей.
2. Открой файл и замени `NotImplementedError` своей реализацией.
3. Выполни `python practice/run.py grade E38`. До реализации команда обязана завершаться ошибкой.
4. Добавь свой граничный пример в отдельный тест: fixture cases проверяют минимум, а не все возможные ошибки.
5. Сохрани решение, результат проверки и два предложения о бизнес-последствии ошибки в своём форке.

## Пример входа и ожидаемого результата

```json
{
  "input": [
    {
      "answer": "100",
      "expected": "100",
      "forbidden": false
    },
    {
      "answer": "secret",
      "expected": "abstain",
      "forbidden": true
    }
  ],
  "expected": {
    "total": 2,
    "correct": 1,
    "critical_failures": 1
  }
}
```

Остальные проверочные cases находятся в [cases.json](cases.json). Не подставляй ответы из fixtures: проверяй правило на собственном примере.

## Подсказка

Не скрывай forbidden disclosure средним score.
