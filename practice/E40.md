# E40. Capstone: report contract

**Модуль:** ИИ, ML и портфолио. **Время:** 30–90 минут. **Prerequisites:** [связанный урок](../roadmap/10-ai-career/099-portfolio.md).

## Условие

Проверь report: total_events==expected_events, ledger_balanced=true, critical_exceptions=0 и source_version непустая. Верни publish или blocked.

Контракт `solve(data) -> JSON-compatible result`. Все входы синтетические; функция не должна менять вход. Для этого упражнения используй стандартную библиотеку Python. Несогласованные входы обрабатывай только так, как явно требует условие.

## Как начать

1. Из корня репозитория выполни `python practice/run.py init E40`. Это создаст личную копию `work/answers/E40.py` без перезаписи существующей.
2. Открой файл и замени `NotImplementedError` своей реализацией.
3. Выполни `python practice/run.py grade E40`. До реализации команда обязана завершаться ошибкой.
4. Добавь свой граничный пример в отдельный тест: fixture cases проверяют минимум, а не все возможные ошибки.
5. Сохрани решение, результат проверки и два предложения о бизнес-последствии ошибки в своём форке.

## Пример входа и ожидаемого результата

```json
{
  "input": {
    "total_events": 6,
    "expected_events": 6,
    "ledger_balanced": true,
    "critical_exceptions": 0,
    "source_version": "fixture-v1"
  },
  "expected": "publish"
}
```

Остальные проверочные cases находятся в [cases.json](cases.json). Не подставляй ответы из fixtures: проверяй правило на собственном примере.

## Подсказка

Готовность требует нескольких независимых свидетельств; toy gate не заменяет financial approval.
