# E08. SQL: uniqueness violations

**Module:** SQL and databases. **Time:** 30–90 minutes. **Prerequisites:** [related lesson](../roadmap/02-sql/019-query-quality.md).

## Task

Return event_id and count for repeated IDs. Successful quality verification returns an empty result.

Contract: `solve(data) -> JSON-compatible result`. All inputs are synthetic; do not mutate the input. Use Python's standard library. Handle invalid inputs only as explicitly required by this task.

## Get started

1. From the repository root, run `python practice/run.py init E08`. It creates your personal copy at `work/answers/E08.py` without overwriting an existing file.
2. Open the file and replace `NotImplementedError` with your implementation.
3. Run `python practice/run.py grade E08`. Before implementation, this command must fail.
4. Add your own boundary case in a separate test: the provided cases cover a minimum, not every possible defect.
5. Save your solution, verification result, and two sentences explaining the business impact of the mistake in your fork.

## Hint

GROUP BY and HAVING expose duplicates; DISTINCT output does not prove clean input.
