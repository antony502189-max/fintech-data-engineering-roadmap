# E03. Boundary contract

**Module:** Engineering foundations. **Time:** 30–90 minutes. **Prerequisites:** [related lesson](../roadmap/01-foundations/003-python.md).

## Task

Validate the strict event contract. Return accepted or rejected; booleans must not qualify as integer amounts.

Contract: `solve(data) -> JSON-compatible result`. All inputs are synthetic; do not mutate the input. Use Python's standard library. Handle invalid inputs only as explicitly required by this task.

## Get started

1. From the repository root, run `python practice/run.py init E03`. It creates your personal copy at `work/answers/E03.py` without overwriting an existing file.
2. Open the file and replace `NotImplementedError` with your implementation.
3. Run `python practice/run.py grade E03`. Before implementation, this command must fail.
4. Add your own boundary case in a separate test: the provided cases cover a minimum, not every possible defect.
5. Save your solution, verification result, and two sentences explaining the business impact of the mistake in your fork.

## Example input and expected result

```json
{
  "input": {
    "event_id": "e",
    "payment_id": "p",
    "kind": "captured",
    "amount_minor": 100,
    "currency": "USD",
    "event_time": "2026-01-01T12:00:00+00:00",
    "received_at": "2026-01-01T12:00:00+00:00"
  },
  "expected": "accepted"
}
```

Other verification cases are in [cases.json](cases.json). Implement the rule rather than hardcoding fixture answers; check it on your own example.

## Hint

Use type(value) is int rather than only isinstance.
