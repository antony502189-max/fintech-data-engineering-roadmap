# E25. Баланс проводок

**Модуль:** Финтех и движение денег. **Время:** 30–90 минут. **Prerequisites:** [связанный урок](../roadmap/07-fintech/062-double-entry.md).

## Условие

По expected_events проверь ровно две postings и sum=0 для каждого event/currency. Верни отсортированные строки event:currency нарушителей. Полностью потерянный журнал тоже ошибка.

Контракт `solve(data) -> JSON-compatible result`. Все входы синтетические; функция не должна менять вход. Для этого упражнения используй стандартную библиотеку Python. Несогласованные входы обрабатывай только так, как явно требует условие.

## Как начать

1. Из корня репозитория выполни `python practice/run.py init E25`. Это создаст личную копию `work/answers/E25.py` без перезаписи существующей.
2. Открой файл и замени `NotImplementedError` своей реализацией.
3. Выполни `python practice/run.py grade E25`. До реализации команда обязана завершаться ошибкой.
4. Добавь свой граничный пример в отдельный тест: fixture cases проверяют минимум, а не все возможные ошибки.
5. Сохрани решение, результат проверки и два предложения о бизнес-последствии ошибки в своём форке.

## Пример входа и ожидаемого результата

```json
{
  "input": {
    "expected_events": [
      [
        "a",
        "USD"
      ],
      [
        "b",
        "EUR"
      ]
    ],
    "postings": [
      {
        "event": "a",
        "currency": "USD",
        "amount": 100
      },
      {
        "event": "a",
        "currency": "USD",
        "amount": -100
      }
    ]
  },
  "expected": [
    "b:EUR"
  ]
}
```

Остальные проверочные cases находятся в [cases.json](cases.json). Не подставляй ответы из fixtures: проверяй правило на собственном примере.

## Подсказка

Не проверяй только уже существующие GROUP BY keys.
