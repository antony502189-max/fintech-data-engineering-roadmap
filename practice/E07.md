# E07. SQL: последняя версия

**Модуль:** SQL и базы данных. **Время:** 30–90 минут. **Prerequisites:** [связанный урок](../roadmap/02-sql/014-windows.md).

## Условие

Верни payment_id, kind для максимального seq каждого payment. При одинаковом seq используй event_id DESC. Сортируй payment_id.

Контракт `solve(data) -> JSON-compatible result`. Все входы синтетические; функция не должна менять вход. Для этого упражнения используй стандартную библиотеку Python. Несогласованные входы обрабатывай только так, как явно требует условие.

## Как начать

1. Из корня репозитория выполни `python practice/run.py init E07`. Это создаст личную копию `work/answers/E07.py` без перезаписи существующей.
2. Открой файл и замени `NotImplementedError` своей реализацией.
3. Выполни `python practice/run.py grade E07`. До реализации команда обязана завершаться ошибкой.
4. Добавь свой граничный пример в отдельный тест: fixture cases проверяют минимум, а не все возможные ошибки.
5. Сохрани решение, результат проверки и два предложения о бизнес-последствии ошибки в своём форке.

ROW_NUMBER в подзапросе; seq — source order, не arrival.
