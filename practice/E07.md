# E07. SQL: latest version

**Module:** SQL and databases. **Time:** 30–90 minutes. **Prerequisites:** [related lesson](../roadmap/02-sql/014-windows.md).

## Task

Return payment_id and kind for the maximum seq per payment. Break equal seq values with event_id DESC. Sort by payment_id.

Contract: `solve(data) -> JSON-compatible result`. All inputs are synthetic; do not mutate the input. Use Python's standard library. Handle invalid inputs only as explicitly required by this task.

## Get started

1. From the repository root, run `python practice/run.py init E07`. It creates your personal copy at `work/answers/E07.py` without overwriting an existing file.
2. Open the file and replace `NotImplementedError` with your implementation.
3. Run `python practice/run.py grade E07`. Before implementation, this command must fail.
4. Add your own boundary case in a separate test: the provided cases cover a minimum, not every possible defect.
5. Save your solution, verification result, and two sentences explaining the business impact of the mistake in your fork.
