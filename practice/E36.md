# E36. Retention and holds

**Module:** Platform and security. **Time:** 30–90 minutes. **Prerequisites:** [related lesson](../roadmap/09-platform/085-retention.md).

## Task

Select sorted IDs for deletion when expiry<=today and hold=false. Dates are ISO. Implement the supplied synthetic policy; do not infer legal retention periods.

Contract: `solve(data) -> JSON-compatible result`. All inputs are synthetic; do not mutate the input. Use Python's standard library. Handle invalid inputs only as explicitly required by this task.

## Get started

1. From the repository root, run `python practice/run.py init E36`. It creates your personal copy at `work/answers/E36.py` without overwriting an existing file.
2. Open the file and replace `NotImplementedError` with your implementation.
3. Run `python practice/run.py grade E36`. Before implementation, this command must fail.
4. Add your own boundary case in a separate test: the provided cases cover a minimum, not every possible defect.
5. Save your solution, verification result, and two sentences explaining the business impact of the mistake in your fork.

## Example input and expected result

```json
{
  "input": {
    "today": "2026-02-01",
    "records": [
      {
        "id": "a",
        "expiry": "2026-01-01",
        "hold": true
      },
      {
        "id": "b",
        "expiry": "2026-02-01",
        "hold": false
      },
      {
        "id": "c",
        "expiry": "2026-03-01",
        "hold": false
      }
    ]
  },
  "expected": [
    "b"
  ]
}
```

Other verification cases are in [cases.json](cases.json). Implement the rule rather than hardcoding fixture answers; check it on your own example.

## Hint

A hold takes priority over expiry.
