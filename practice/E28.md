# E28. Распределение оплаты кредита

**Модуль:** Финтех и движение денег. **Время:** 30–90 минут. **Prerequisites:** [связанный урок](../roadmap/07-fintech/067-credit.md).

## Условие

По заданному учебному waterfall fee→interest→principal распредели неотрицательный integer payment. Верни allocations и unallocated.

Контракт `solve(data) -> JSON-compatible result`. Все входы синтетические; функция не должна менять вход. Для этого упражнения используй стандартную библиотеку Python. Несогласованные входы обрабатывай только так, как явно требует условие.

## Как начать

1. Из корня репозитория выполни `python practice/run.py init E28`. Это создаст личную копию `work/answers/E28.py` без перезаписи существующей.
2. Открой файл и замени `NotImplementedError` своей реализацией.
3. Выполни `python practice/run.py grade E28`. До реализации команда обязана завершаться ошибкой.
4. Добавь свой граничный пример в отдельный тест: fixture cases проверяют минимум, а не все возможные ошибки.
5. Сохрани решение, результат проверки и два предложения о бизнес-последствии ошибки в своём форке.

## Пример входа и ожидаемого результата

```json
{
  "input": {
    "payment": 1200,
    "due": {
      "fee": 100,
      "interest": 200,
      "principal": 1000
    }
  },
  "expected": {
    "fee": 100,
    "interest": 200,
    "principal": 900,
    "unallocated": 0
  }
}
```

Остальные проверочные cases находятся в [cases.json](cases.json). Не подставляй ответы из fixtures: проверяй правило на собственном примере.

## Подсказка

Conservation: все allocations + remainder = payment.
