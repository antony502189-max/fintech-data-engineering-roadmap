# E21. DAG ordering and cycles

**Module:** Transformations and orchestration. **Time:** 30–90 minutes. **Prerequisites:** [related lesson](../roadmap/06-transformation/053-orchestration.md).

## Task

Return topological order from dependency mapping. Choose the alphabetically first ready node each step. Return cycle if none is ready. All dependency nodes exist in the mapping.

Contract: `solve(data) -> JSON-compatible result`. All inputs are synthetic; do not mutate the input. Use Python's standard library. Handle invalid inputs only as explicitly required by this task.

## Get started

1. From the repository root, run `python practice/run.py init E21`. It creates your personal copy at `work/answers/E21.py` without overwriting an existing file.
2. Open the file and replace `NotImplementedError` with your implementation.
3. Run `python practice/run.py grade E21`. Before implementation, this command must fail.
4. Add your own boundary case in a separate test: the provided cases cover a minimum, not every possible defect.
5. Save your solution, verification result, and two sentences explaining the business impact of the mistake in your fork.
