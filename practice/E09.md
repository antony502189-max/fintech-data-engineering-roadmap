# E09. SCD2 boundary lookup

**Module:** DWH modeling. **Time:** 30–90 minutes. **Prerequisites:** [related lesson](../roadmap/03-modeling/025-scd2.md).

## Task

Choose a customer's tier from valid-time intervals [from,to). Return null when no version exists. Fixture timestamps are already normalized UTC ISO values.

Contract: `solve(data) -> JSON-compatible result`. All inputs are synthetic; do not mutate the input. Use Python's standard library. Handle invalid inputs only as explicitly required by this task.

## Get started

1. From the repository root, run `python practice/run.py init E09`. It creates your personal copy at `work/answers/E09.py` without overwriting an existing file.
2. Open the file and replace `NotImplementedError` with your implementation.
3. Run `python practice/run.py grade E09`. Before implementation, this command must fail.
4. Add your own boundary case in a separate test: the provided cases cover a minimum, not every possible defect.
5. Save your solution, verification result, and two sentences explaining the business impact of the mistake in your fork.

## Example input and expected result

```json
{
  "input": {
    "customer": "c",
    "at": "2026-01-02",
    "versions": [
      {
        "customer": "c",
        "from": "2026-01-01",
        "to": "2026-01-02",
        "tier": "basic"
      },
      {
        "customer": "c",
        "from": "2026-01-02",
        "to": null,
        "tier": "premium"
      }
    ]
  },
  "expected": "premium"
}
```

Other verification cases are in [cases.json](cases.json). Implement the rule rather than hardcoding fixture answers; check it on your own example.

## Hint

The closing boundary is excluded.
