# E17. Partition pruning

**Module:** Storage and processing. **Time:** 30–90 minutes. **Prerequisites:** [related lesson](../roadmap/05-storage/042-partitioning.md).

## Task

Sum bytes only for partitions with start<=day<end. This is an offline pruning calculation, not an engine benchmark.

Contract: `solve(data) -> JSON-compatible result`. All inputs are synthetic; do not mutate the input. Use Python's standard library. Handle invalid inputs only as explicitly required by this task.

## Get started

1. From the repository root, run `python practice/run.py init E17`. It creates your personal copy at `work/answers/E17.py` without overwriting an existing file.
2. Open the file and replace `NotImplementedError` with your implementation.
3. Run `python practice/run.py grade E17`. Before implementation, this command must fail.
4. Add your own boundary case in a separate test: the provided cases cover a minimum, not every possible defect.
5. Save your solution, verification result, and two sentences explaining the business impact of the mistake in your fork.

## Example input and expected result

```json
{
  "input": {
    "start": "2026-01-01",
    "end": "2026-01-03",
    "partitions": [
      {
        "day": "2026-01-01",
        "bytes": 100
      },
      {
        "day": "2026-01-02",
        "bytes": 200
      },
      {
        "day": "2026-01-03",
        "bytes": 300
      }
    ]
  },
  "expected": 300
}
```

Other verification cases are in [cases.json](cases.json). Implement the rule rather than hardcoding fixture answers; check it on your own example.

## Hint

Use a half-open interval and exclude the end partition.
