## Follow-up review

The learning brief emphasized practical work. Forty runnable exercises supplement assignments in all lessons, with starters, references, and grading. Four tasks per module provide an initial pass; actual platform capabilities need integration extensions.

Sources include official CMU links, Zoomcamp, Confluent, and Stripe/Monzo/Uber articles. Each has a follow-up task. External text, diagrams, and homework were not copied. Version 1.1.0 makes every current lesson and guide English.

## Further improvements

Collect confusing-task reports, add targeted examples, expand meaningful boundary cases, document verified tool integrations with pinned versions, and regularly review source links. Preserve attribution when replacing outdated commands or resources.
